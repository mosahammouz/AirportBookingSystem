✈️ Airport Ticket Booking System (Console App - C#)

A simple yet powerful .NET Console Application for managing airport flights and bookings using file-based storage (CSV system).

---

## 🛠️ Technologies & Concepts Used

This project was built using modern C# and .NET concepts, including:

---

### 💻 Core Technologies
- C# (.NET Console Application)
- File-based storage (CSV files)
- Object-Oriented Programming (OOP)

---

### ⚡ Language Features
- Classes & Objects
- Constructors
- Properties (get/set)
- Enums
- Exception Handling (try/catch)

---

### 🔍 Data Handling
- LINQ (Language Integrated Query)
- Filtering (Where)
- Searching (FirstOrDefault)
- Projection (Select)
- Sorting (OrderBy)
- Collection manipulation (List)

---

### 📁 File System
- System.IO namespace
- Reading and writing CSV files
- Data persistence without a database

---

### 🧠 Architecture Concepts
- Separation of concerns (Services / Models / Data layer)
- Basic repository-like structure using files
- Input validation

---

### 🎨 Console UI
- Colored console output (Console.ForegroundColor)
- Menu-driven navigation system
